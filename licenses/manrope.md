# Manrope

The UI font of the app (`src/assets/fonts/manrope-*.woff2`). Policy: fonts only under the SIL Open Font License (like Bravura, see `licenses/Bravura-OFL-1.1.txt`).

## Source

- **Font:** Manrope, variable, weights 400–800, by Mikhail Sharanda (The Manrope Project Authors)
- **Project:** https://github.com/sharanda/manrope; the Google Fonts release is in https://github.com/google/fonts/tree/main/ofl/manrope
- **Files used:** the four WOFF2 subsets served by the Google Fonts CSS API for `Manrope:wght@400..800` (version 23): `latin`, `latin-ext`, `cyrillic`, `cyrillic-ext`. They cover English, German, French, and Ukrainian. Greek and Vietnamese subsets are not included.
- **Licence:** SIL Open Font License 1.1. Copyright line from the licence file: "Copyright 2018 The Manrope Project Authors (https://github.com/googlefonts/manrope)". The full text is in `licenses/Manrope-OFL-1.1.txt`, copied from `ofl/manrope/OFL.txt` in the Google Fonts repository.
- **Checked:** 2026-11-01.

## Changes made

None. The WOFF2 files are the unmodified subsets from Google Fonts, served from the app's own origin, so a visit does not contact Google.
