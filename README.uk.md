# Piano Tutor

Веб-застосунок для навчання гри на фортепіано у форматі гри: підключіть MIDI-клавіатуру (Web MIDI) і отримуйте миттєвий відгук, чи правильні ноти ви граєте. Лише клієнтська частина, без бекенду. Див. [specs/mission.md](specs/mission.md).

> Статус: фази 1–15 завершено. Вільна гра з MIDI-клавіатурою, клавіатурою комп'ютера або екранним піаніно; курс першого тижня з 13 уроків; локальний прогрес (зірки, XP, рівні, щоденна серія); встановлюваний застосунок, що працює офлайн (PWA); адаптивне екранне піаніно; Плеєр MIDI-файлів із нотами; бібліотека з 34 класичних творів у суспільному надбанні; **курси**, які навчають початку твору з бібліотеки руку за рукою. Застосунок розгорнуто онлайн (див. «Розгортання»). Далі — див. [specs/roadmap.md](specs/roadmap.md).

> Цей файл — переклад [README.md](README.md) (першоджерело — англійська версія). Якщо є розбіжності, орієнтуйтеся на англійську.

## Вимоги

- [Bun](https://bun.sh) (npm теж підходить)
- Браузер на базі Chromium (Chrome, Edge) для Web MIDI. В інших браузерах можна грати на екранному піаніно та клавіатурою комп'ютера.

## Початок роботи

```bash
bun install
bun run dev      # http://localhost:3000
```

## Як грати

- **MIDI-клавіатура:** натисніть **Connect MIDI keyboard** (підключити MIDI-клавіатуру) і дайте доступ. Працює кожна підключена клавіатура, зокрема педаль сустейну. Web MIDI потребує Chrome або Edge і захищеної сторінки (HTTPS або `localhost`).
- **Клавіатура комп'ютера:** `A S D F G H J K L ;` — білі клавіші (до ре мі фа соль ля сі до ре мі), `W E T Y U O P` — чорні. Лівий `Shift` (`⇧`) грає сі, що лежить просто під першою до. `Z` / `X` зсувають октаву вниз / вгору. Клавіші визначаються за фізичним положенням, тож це працює й на розкладках QWERTZ та AZERTY.
- **Екранне піаніно:** клікайте або торкайтеся клавіш. Піаніно має ширину вікна і показує більше октав, коли вони вміщуються (клавіші не вужчі за 40 px, до всіх 88 клавіш на широкому моніторі). На вузькому телефоні клавіші лишаються зручними для пальців, а піаніно прокручується вбік: проводьте пальцем по лінійці октав над клавішами (проведення по клавішах грає їх). Кнопки октав і `Z` / `X` зсувають діапазон, який грає клавіатура комп'ютера (типово B2–C5: сі під першою до, дві октави і верхня до), а вигляд іде за ними.
- **Розмір клавіатури:** кнопка **Keyboard** біля статусу MIDI (з’являється, коли доступний Web MIDI, і зникає під час уроку) повідомляє застосунку, скільки клавіш має ваша справжня клавіатура: оберіть 25, 37, 49, 61, 76 або 88 клавіш і пересуньте діапазон на октави, якщо він починається з іншої ноти, або натисніть **Calibrate**, зіграйте найнижчу, а потім найвищу клавішу вашої MIDI-клавіатури й збережіть результат (підійде будь-який розмір). Налаштування зберігається на вашому пристрої. Клавіші екранного піаніно поза діапазоном затемнені (вони все одно грають), а урок із нотами, яких немає на вашій клавіатурі, показує повідомлення з їх кількістю; урок лишається доступним для гри. Поки ви не оберете розмір, нічого не задано.
- **Головна й уроки:** застосунок відкривається на **Home** (Головна) з 13 уроками у п'яти розділах: права рука (скрипковий ключ), ліва рука (басовий ключ), обидва ключі, мелодії (Mary Had a Little Lamb, Ode to Joy, Twinkle Twinkle), інтервали та акорди. Натисніть **Start** на картці уроку; урок із позначкою **Next** — перший, який ви ще не завершили, але нічого не заблоковано. На нотному стані — ряд нот: підсвічена нота — та, яку треба зіграти, зіграні стають сірими. Для акорду зіграйте всі його ноти в будь-якому порядку. Неправильна клавіша рахується як помилка, а ціль лишається, доки ви не зіграєте правильно. Наприкінці ви бачите точність, 1–3 зірки та XP. У випадкових уроках порядок нот щоразу новий.
- **Плеєр:** режим **Player** відкриває MIDI-файл (`.mid`, формати 0 і 1, до 2 МБ) через вікно вибору файлу. Файл читається на вашому пристрої й нікуди не надсилається. Він показується як ноти (ключові знаки, дієзи й бемолі, тривалості нот, паузи, такти, ліги; ребра в межах долі; спрощена версія з одним голосом, без тріолей; відстань між нотоносцями більшає, коли між ними є ноти) системами, і відтворюється з рухомим курсором, а клавіші, що звучать, підсвічуються синім. **Play** / **Pause** / **Stop**, повзунок темпу (50–150 %) і повзунок позиції (або клік по нотах) дозволяють переміщатися. Ударні пропускаються.
- **MuseScore / MusicXML:** Плеєр також відкриває партитуру, експортовану з MuseScore (**Файл → Експорт → MusicXML**), як стиснутий `.mxl` або звичайний `.musicxml` / `.xml` (до 2 МБ); формат визначається за вмістом. Усі партії об’єднуються, ударні пропускаються, твір грає один раз із темпом 120 уд./хв, як записано (темпові позначки, повтори та форшлаги ігноруються; повзунок темпу працює). У партії з двома нотоносцями верхній — права рука, нижній — ліва, тому кнопка **Learn** біля назви файлу будує курс (як для твору з бібліотеки), у якому кожна нота у своїй руці. **Learn** працює й для вашого власного `.mid` (там руки ділить середнє до). Зірки та XP такого курсу зберігаються на вашому пристрої, але сам файл не зберігається, тож на Home його немає; відкрийте той самий файл знову, щоб побачити зірки.
- **Бібліотека:** кнопка **Library** у Плеєрі відкриває 34 класичні фортепіанні твори 10 композиторів (Бах, Бетховен, Брамс, Бургмюллер, Шопен, Гендель, Гайдн, Моцарт, Шуберт, Шуман), згруповані за композитором, із портретом кожного та оцінкою від 1 (початковий) до 5 (експерт). Фільтруйте за складністю або улюбленими, оберіть твір і натисніть **Play**. Позначайте твори як улюблені (★) або виконані (☑); позначки лишаються на вашому пристрої. Твір, який ви хоч раз відкрили, відкривається й офлайн. Файли — механічне відтворення нотного тексту, тож звучать точно, але не виразно.
- **Вивчити твір:** натисніть **Learn** біля будь-якого твору бібліотеки (або в його інформаційному рядку над нотами). Застосунок будує **курс** із початку твору (перші 6 частин, кожна до 4 тактів) і впорядковує уроки від найпростішого до найскладнішого. Спершу для **правої руки**, потім для **лівої**: прочитати ноти, які є у творі, потім його акорди (якщо вони є), потім частини по одній, потім частини, з'єднані разом (1–2, 3–4, 5–6, 1–4, 1–6). Далі **обидві руки разом**: частини, потім з'єднані частини. Кожен урок показує справжні ноти твору з поточним кроком синього кольору; ви граєте те, що бачите, а застосунок оцінює ноти (не ритм). Нічого не заблоковано, позначка **Next** вказує перший незавершений урок, а на Home видно твори, які ви вивчаєте. Обидві руки разом можуть потребувати кількох пальців або клавіш одночасно, тож тут допоможе екранне піаніно або MIDI-клавіатура.
- **Прогрес:** XP підвищує ваш рівень, а щонайменше один завершений урок на день будує щоденну серію. Усе зберігається лише на вашому пристрої; **Reset progress** на Home стирає це.

## Бібліотека

Твори — це MIDI-файли з [Mutopia Project](https://www.mutopiaproject.org/), що лежать у `public/library/<composer>/`. Використовуються **лише твори, на власній сторінці яких Mutopia пише «Public Domain»** (поле «Copyright»). Mutopia Project публікує також твори під CC-BY і CC-BY-SA, які вимагають зазначення авторства або однакових умов поширення; їх не використовуємо, а `src/core/library.test.ts` падає, якщо в твору інша ліцензія. Портрети композиторів — картини, малюнки й фотографії у суспільному надбанні з [Wikimedia Commons](https://commons.wikimedia.org/) (сторінка Commons має казати «Public domain»; тест не допускає іншого). Джерело, ліцензія й дата перевірки кожного твору та портрета є в [licenses/library-sources.md](licenses/library-sources.md) і в каталозі (`src/core/libraryCatalog.ts`). Це облік, а не юридична порада. Зверніть увагу: власний фільтр «Public Domain» на Mutopia також показує твори з CC, тож завжди читайте сторінку твору.

Щоб додати твір:

1. Відкрийте сторінку твору на mutopiaproject.org і переконайтеся, що там **Copyright: Public Domain**. Візьміть один файл `.mid` (не архів).
2. Збережіть його як `public/library/<composer>/<slug>.mid`, де slug — рядкові літери, цифри та дефіси.
3. Додайте запис до `LIBRARY_PIECES` у `src/core/libraryCatalog.ts`: id з Mutopia, звичну назву з номером опуса чи каталогу, тривалість у секундах і складність від 1 до 5 (рубрика — у [specs/phase-10-midi-library/requirements.md](specs/phase-10-midi-library/requirements.md), FR-4). Новому композитору потрібен запис у `LIBRARY_COMPOSERS` (із портретом у суспільному надбанні з Wikimedia Commons, збереженим як квадратний JPEG до 40 КБ у `public/library/portraits/`) та ім'я `composer…` у всіх чотирьох локалях.
4. Додайте рядок до `licenses/library-sources.md`.
5. Запустіть `bun run test`: він перевіряє ліцензію, файл, його тривалість і розмір.

## Встановлення й офлайн

Piano Tutor — веб-застосунок, який можна встановити (PWA). Відкрийте його раз онлайн; далі він працює без з'єднання: уроки, вільна гра, звук, прогрес і MIDI-вхід.

- **Встановлення:** у Chrome (Android або комп'ютер) на Home є картка **Install**, або скористайтеся меню браузера / значком встановлення в адресному рядку. **Not now** ховає картку назавжди.
- **Оновлення:** коли розгорнуто нову версію, банер пропонує **Reload** або **Later**. Застосунок ніколи не перезавантажується сам, а банер чекає, доки ви вийдете з уроку. Прогрес і налаштування зберігаються.
- **Розробка:** у `bun run dev` немає service worker. Щоб спробувати офлайн-режим, скористайтеся `bun run build && bun run preview`.
- **Іконка:** намальована як `public/icon.svg`. Після зміни запустіть `bun run icons`, щоб перегенерувати файли PNG та ICO, і закомітьте їх.

## Скрипти

| Скрипт                 | Що робить                                           |
| ---------------------- | --------------------------------------------------- |
| `bun run dev`          | Сервер розробки на http://localhost:3000            |
| `bun run build`        | Перевірка типів + збірка для продакшену в `dist/`   |
| `bun run preview`      | Локально віддає збірку для продакшену               |
| `bun run lint`         | Перевірка типів TypeScript, потім ESLint            |
| `bun run format`       | Форматує всі файли Prettier                         |
| `bun run format:check` | Падає, якщо якийсь файл не відформатовано           |
| `bun run test`         | Один раз запускає модульні тести (Vitest)           |
| `bun run icons`        | Перегенеровує іконки застосунку з `public/icon.svg` |

CI (GitHub Actions) запускає `lint`, `format:check`, `build` і `test` для кожного pull request і кожного push до `main`.
